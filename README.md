# TI-84_CE_spriteLibrary
This is a C library (with python helper programs) designed to help build/compile sprites for the TI-84 CE calculator and render those sprites on the LCD

The libload folder contains all the libload library dependencies that my system relies on. You can learn more here: https://github.com/CE-Programming/libraries/releases.

Please note that to actually use this library/system, you will need to compile your c code into 8xp files using the CEdev compiler. You can download that here: https://github.com/CE-Programming/toolchain/releases.

The tilegame folder contains an example project I created using this sprite system.
